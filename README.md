# Basketlytics

## Basketlytics

Basketlytics is an analytics dashboard for analysts and casual NBA fans. It will let users explore and compare player and team statistics across games, quarters, and seasons, including offensive and defensive performance, home-versus-away results, player efficiency and more.
## 0. Getting started
### Prerequisites
- Python3, python3-venv, python3-kaggle
- Installing all prerequisites (example using Ubuntu, replace 'apt' with your distro's package manager):
```bash
sudo apt install python3-venv -y

python3 -m venv myenv
source myenv/bin/activate

pip install kagglehub
```
### Downloading the dataset
- Must have python venv running:
```bash
source myenv/bin/activate
```
- From the root of the repository, run:
```bash
python3 src/read_nba_database.py
```
- The script will download the dataset and prints its location, then it will copy that dataset to './cmpe138_project'
- Example output:
```bash
Path to dataset files: /home/name/.cache/kagglehub/datasets/wyattowalsh/basketball/versions/238
```
